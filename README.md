# Systems Integration Project (25/26)

This repository contains the files for the Systems Integration Project (Academic Year 2025/2026).

## Context
This project focuses on the integration of various systems using modern technologies and architectures. The main component is the **SOMIOD** project, which implements the necessary services and endpoints to fulfill the requirements of the course. The solution aims to provide a robust and scalable integration layer, enabling seamless communication and data exchange between different software components.

## Project Structure
- `Data/`: Contains data files used in the project.
- `Other/`: Miscellaneous files.
- `Project/`: Main project source code (includes the SOMIOD application).
- `Report/`: Project report files (e.g., `IS_Project_Report_2025-2026.pdf`).
